## 設計ノートを実データに当てるときの決めごと

- **期間と区切り**: 保有月は 1986-01〜2026-08 の 488 か月。区切りの日と金利が全月で揃うことを、日付と金利の有無だけで

  間は空かない
- **Plan の値**: ブートストラップの乱数の種は `20260927`。他の値（順位のラグ 3 か月、`K = floor(N/3)`、売買コスト 3 bp、
  ブートストラップ 10,000 回・ブロック 6 か月、棄却の閾値 0.30、感応度の倍率 0 と 2）は設計ノートのとおり
- **副統計の歪度**は、補正なしの標本歪度（第 3 中心モーメント ÷ 第 2 中心モーメントの 1.5 乗）とする。判定には使わない
- **全期間の最後に持ち高を閉じるコスト**は数えない。建て替えのたびの売買だけを数える

## 結果の読み方（事前に決めておく）

- 判定の規則は設計ノートのとおり。支持は「全期間の片側 95% 下限 > 0 かつ発表後の点推定 > 0」、棄却は「全期間か発表後の
  片側 95% 上限 < 0.30」、両方を満たせば棄却、それ以外は判定不能
- 全期間の 1986〜2009 年ごろは先行研究の標本と重なる。支持でも、その多くは既知の結果の再現であり、発表後の点推定が正で
  あることは「崩れていない」ことしか示さない
- 持ち高はほぼ「NZ ドルと豪ドルを買い、スイスフランとユーロを売る」1 つの賭けになる見込みで、分散は効かない。結果はその
  前提で読む
- 判定不能を「効果が無い」とは読まない
- 支持なら、月次のキャリー戦略として設計し、AUD・NZD・CAD・CHF のペアを基盤に加えて最小単位で forward で動かす。
  棄却なら止めて記録する。判定不能なら運用には進まない

## 解釈

- **判定は事前に決めた規則どおり「支持」だが、その中身は弱い。** 全期間の下限は 0 をわずか 0.023 上回っただけで、発表後の
  点推定 0.006 は 0 と区別できない。規則が発表後に求めたのは「点推定が 0 を超える」ことだけで、今回それを満たしたのは
  年 0.02% の差である
- **全期間の正は、主に 2012 年までの高金利差の時代による。** 発表前は金利差が年 2.9% あり、純シャープレシオは 0.37 だった。
  発表後は金利差が年 1.4% に縮み、為替の変化（−0.7%）とスワップの上乗せ（−0.6%）でほぼ消えた
- **発表後に残っていた取り分は、OANDA のスワップの上乗せとほぼ同じ大きさだった。** 上乗せを除けば発表後の点推定は 0.18、
  2 倍にすれば −0.17 になる。個人の口座で取れるかどうかは、上乗せの大きさで決まる。今回の上乗せは 2026-09 の 1 回の記録を
  全期間に当てたもので、上乗せが時期によってどれだけ動くかは測っていない
- **危機でまとめて払う形は、設計ノートの仕組みどおりに出た。** 最大の損失は 2008 年の金融危機で、歪度は負だった
- 事前に決めた扱いでは、支持なら月次のキャリー戦略として設計し、AUD・NZD・CAD・CHF のペアを基盤に加えて最小単位で forward で
  動かす。ただし発表後の純リターンがほぼ 0 なので、forward で期待できる利益もほぼ 0 と読むのが正直である。forward を行う
  意味は、利益よりも、実際のスワップと約定のコストを時間をかけて測ることにある
