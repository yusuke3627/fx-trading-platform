Issue #222（親 #157 候補2）の研究専用条件。`breakout_first_pullback` v0.1.0 は `RESEARCH_ONLY`、すべての環境で既定無効とする。H6の棄却は維持する。以下は損益の測定前に固定した初期条件で、収益性や実運用への昇格を意味しない。

## 突破の識別と固定値

- 既定時間足はH1/M5、対象はUSDJPY。設定と `InstrumentSpec.pip_size` を使い、価格計算はDecimalで行う。共有指標関数の計算だけは既存のfloatを使う。
- 確定H1足を含む連続21本を使う。突破足を除く直前20本の最大高値を終値が厳密に超え、EMA20が直前値より上ならLONG。最小安値未満かつEMA低下ならSHORT。等値では成立しない。
- EMAはこの21本の最初の20終値の単純平均を初期値とする共有 `ema_series`。その初期値と21本目のEMAを比較する。設定変更時の読取本数は `max(breakout_lookback_bars + 1, ema_period + 1)` だが、EMAへ渡すのは末尾 `ema_period + 1` 本だけで、より古い履歴を追加しない。
- 既定の21本EMAでは、直前20本の最大高値を終値が超えれば、その終値は直前20終値の平均も超えるため、EMA上向き条件は数学的に自動成立する（SHORTも対称）。この条件を独立した方向gateの追加効果として評価しない。
- H1足がPIT上初めて見えた評価でのみ候補を作る。`now - known_at` が0〜5秒の足だけを採用する。起動時の古い突破や後から訂正された同じ開始時刻のH1を再利用しない。
- その時点のM5 ATR14を固定する。共有 `IndicatorService` の最大200本（期間を広げた場合は `max(200, period + 1)`）によるWilder ATR。直近15本は連続し、最新M5のbroker終了ラベルが突破H1のbroker終了ラベルと一致することを要求する。より古いATR履歴に市場休止による空白があること自体は棄却しない。
- 突破水準、ATR、許容帯の半幅 `0.25 × ATR` は候補の存続中に更新しない。ストップ余裕も同じ固定ATRの0.25倍。

## 接触、期限、欠測

突破H1のbroker終了ラベルを最初のM5開始ラベルとする。各M5の `[low, high]` が突破水準の±許容幅と重なった確定足を「接触」と呼ぶ。LONGはその足の終値が突破水準を厳密に上回れば反発成立、SHORTは下回れば成立。接触足のopenの向きは条件にしない。

期限は突破H1の `known_at + 3600秒`。ちょうど期限の評価は許可し、期限を超えた評価は棄却する。新しいH1と最後のM5が同時に見えた場合は古い候補のM5を先に評価する。その後、新しいH1の候補へ置き換える。

M5の最初の開始ラベル、続くすべての開始ラベルが期待値と完全一致することを要求する。最初のM5も含め、一つでも欠落した後の足が来たら候補を失効する。欠落中にあったはずの初回接触を推定・補間しない。未来足はMarketDataServiceのPIT可視性に従い参照しない。

`known_at` とClockは実UTCで、期限・確定足鮮度・セッションに使う。`Bar.start/close_time` と `Tick.time` はbroker時計のラベルで、バーの連続性・順序と最新確定足からのquote経過にだけ使う。両時計を直接減算しない。

## 初回限定の比較

- `first_pullback_only=true`: 最初の接触足で候補を消費する。反発不成立、session閉鎖、保有中、価格・spread・鮮度gate失格でも、その後の足や同じ足の別tickで再試行しない。
- `first_pullback_only=false`: 不成立・gate失格の接触の後も、期限内の後続接触足を評価する。各確定足は一度だけ評価し、同じ足の後続tickでは再試行しない。
- 両条件とも最初のsignal発行時に候補を消費する。Portfolio/Risk拒否でも再発行しない。初回接触が不成立で次の接触が成立する系列、および初回接触が価格gate失格となる系列で、ONでは0件、OFFでは1件となる対照試験を行う。

## 新規、価格、出口

新規signalは保有なし、既存session profileが許可する時間帯だけ。保有中の新しい突破・接触は増し玉にも反対売買にも変換しない。

接触足の `known_at` と最新tickの受信時刻は、評価時刻から0〜5秒以内でなければならない。同時に `tick.time - bar.close_time` も0〜5秒以内とする。古いquoteの遅着や次の足へ入った後の遅れた確認で新規を出さない。LONGは `突破水準 < Ask <= 突破水準 + 許容幅`、SHORTは `突破水準 - 許容幅 <= Bid < 突破水準`。既存SpreadGateを使い、spread/固定ATR上限0.5、USDJPYの絶対spread上限1.5pips。

LONGのストップ基準は接触足の安値から固定ATRの0.25倍下、SHORTは高値から同幅上。実行側のAsk/Bidからこの基準までの距離をpipsへ変換し小数1桁へ丸める。利確距離はそのストップ距離の厳密な2倍。Strategyは距離を渡し、Portfolioが判断時quoteのAsk/BidからSL/TPの絶対価格を作る。Simulatorはその絶対価格を引き継ぎ、slippage後の実際の約定価格から再計算しない。このため2Rは判断時quoteを基準にした距離比で、約定後の実現リスクと利益の比が厳密に2になる保証はない。Riskの可否と数量、保護注文による決済は既存経路が担当する。

最大保有は既存 `_horizon_exit` の4時間。計測起点は保有を最初に観測したsnapshotの `as_of` で、brokerの真の約定時刻そのものとは限らない。session閉鎖後も `exit_only` を発行する。保護注文で既に決済済みなら、新たな裸の反対売買を出さない。

次のNew York 17:00までの残りが `expected_horizon_seconds + 60秒` 以下なら新規を停止する。IANA `America/New_York` に従う既存session終了時刻で計算し、夏冬時刻へ追随する。60秒は約定・退出の余裕であり、無tickや拒否時も跨がない保証ではない。rolloverを跨いだ測定に未値付けswapがあれば、採否を保留する。

2026-09-22、損益を見る前に以下を固定した。合成入力による利確・損切り・時間切れの到達確認に続いて、保存tickを通した研究CLIの動作と入力品質を確認する。短期間のため、この実行だけでは収益性を採否判定しない。
