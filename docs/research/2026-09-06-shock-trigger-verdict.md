# 実時間ショックトリガーによる介入継続の検証（H2/H3）と棄却判断

- 日付: 2026-09-06
- 対象: 仮説 H2「介入クラスタの初撃のあと数時間は円高が継続する」、対立仮説 H3「H2 は介入固有ではなくボラティリティショック一般の性質である」
- 判断: **H2/H3 とも棄却**（事前登録した判定規則の機械適用）。介入後の短期継続に関する研究系統を閉じ、研究資源を H5（intraday のマクロ確認 ablation）と H4（scalp の基礎エッジ）へ移す
- 関連: PR #105 / #118（介入イベントスタディ）、PR #119（本スタディ CLI と 2026-07-31 エントリ）、PR #120（報道アンカーの独立）、PR #121（政府公式表明の介入イベント）、研究ノート `2026-09-02-monetary-policy-convergence-verdict.md`

## 背景

介入イベントスタディ（`trading.backtest.intervention_event_study`）では、介入クラスタ初回 6 事例のショック足の後に、1 時間で −0.67%、4 時間で −0.93%（hit 83%、CI90 が 0 を外す）の円高継続が観測されていた。ただしショックアンカーは「介入日を含む 36 時間窓で最大の下落 5 分足」であり、その足が最大だと分かるのは窓が閉じた後である。つまり事後選択で、実時間では特定できない。

この結果が (H2) 介入固有の継続か、(H3) 大きな下落ショック一般の性質か、(棄却) 事後選択の産物かを、**その 5 分足が閉じた時点の情報だけで判定できるトリガー**で決着させた。外部レビュー（2026-09-05）の指摘を採り、コスト控除後リターン、グリッドの事前登録、全セル報告、再現情報の出力を仕様に含めた。

## 方法

`trading.backtest.shock_trigger_study`（PR #119）。判定規則とグリッドは実行前に固定し、PR 本文に記録した。

- 足: 保存 tick から 5 分足を bid で畳み、各足に ask 終値を併記
- リターン: 連続する 2 本（`prev.close_time == bar.start`）の間でだけ対数リターンを定義。週末・休場・欠損をまたぐ対は無効
- トリガー: 直近 N 本の有効リターンの平均と母標準偏差（当該足を含めない）から z を計算し、`z < −K かつ r < 0` で発火。発火後 48 本は抑止（初撃のみ）。前向き 4 時間窓に非連続がある発火は無効
- グリッド: N ∈ {48, 96, 288} × K ∈ {3, 4, 5} の 9 仕様。**主仕様 N=96、K=4**（判定はこのセルにだけ適用、他 8 セルは頑健性）
- ホライズン: 15 分・1 時間・4 時間
- gross: bid 終値 → bid 終値。**net: bid で売り、ask で買い戻し**（ショートの往復）。負 = 円高 = ショートの利益
- 層別: A = 介入 `action_date` 00:00（ブローカー時刻）から 36 時間以内（A-first = クラスタ初回の窓）、B = BOJ/FED 決定の `known_at` から 24 時間以内、C = それ以外。A∩B は A
- 統計: 層 × ホライズン × {gross, net} の n / mean / median / hit / CI90（ブートストラップ 2,000 標本、seed 20260828）。無条件ベースラインを併記
- 判定規則（net、1 時間 → 4 時間の順で最初に該当した分岐）:

| 条件 | 判定 |
|---|---|
| A の CI90 が 0 を外して負、かつ C の CI90 が 0 を含む | H2 支持（介入固有） |
| A と C の両方で CI90 が 0 を外して負 | H3 支持（ショック一般） |
| C の mean が正で CI90 が 0 を外し、A が負で CI90 が 0 を外す | H2 強化（通常ショックは逆張り） |
| gross では A が負で CI90 が 0 を外すが、net では 0 を含む | 統計現象だが非取引可能 |
| それ以外 | H2/H3 棄却 |

## 判定

**H2/H3 棄却**（主仕様、net、判定規則の「それ以外」）。

- H3 は明確に棄却。通常日のショック 435 件で平均ゼロ、CI90 は ±0.02% の幅に収まる。USD/JPY の 5 分足に「大きく下げた足の後に続く」性質はなく、9 セルすべてで同じ
- H2 も棄却。A 層の 4 時間は −0.33% で CI90 がかろうじて 0 を含み、hit 率は 50%。唯一 CI90 が 0 を外した A-first の 4 時間（−0.67%）は事前登録の判定対象ではない小層で、hit 率 54% のまま平均だけが左裾に引かれた形である

## 解釈

事後選択の「窓内最大の下落足」は本物の介入足だけを拾っていた。実時間トリガーは同じ窓の中で介入前のショック、二撃目、翌日の二回目にも発火し、それらは即座に戻される。閉じた時点の z や下落率では両者を分離できない。下落率 0.5% 超に絞っても継続は 11 件中 5 件で、クラスタ初回に限って「最初の 0.5% 超」を採っても 6 件中 3 件にとどまる。

さらに A 層の条件「その日に介入があった」自体が事後情報である（介入の認識は当日 23:59 JST の上界で events に入る）。介入があったと知っていてなお hit 率 50% なので、実時間の介入リスク指標（H6）で条件付けしても改善する余地はない。

**介入イベントスタディの −0.93% は「介入後の値動きに継続性がある」ことの記述としては正しいが、取引可能な優位性ではない。**

## 教訓

- 事前登録は機能した。3 事例で見えた 10 日反転が 6 事例で消え、6 事例で見えた日中継続が実時間トリガーで消えた。どちらも判定基準を先に固定していたから、結果を見てから基準を動かす誘惑を避けられた
- 「窓内で最大」「事後に分かるクラスタ初回」のような選択は、結果を見せる力が強いぶん、実時間の再現性を必ず別の測定で確かめる。研究のアンカーと戦略のトリガーは別物である
- 介入は 4 年で 12 事例しかなく、介入固有の性質を統計的に確定する標本は当面得られない。介入は戦略の条件ではなく、リスク（スプレッド拡大、IOC 不約定）として扱う
